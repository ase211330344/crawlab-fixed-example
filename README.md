# Crawlab

基于 Crawlab 二次修改的爬虫管理平台，修复并调整了 Git 集成、环境依赖隔离、分页筛选缓存、任务最大运行时间等功能，并去除了结果直接入库流程。

## 快速开始

请先安装 Docker 和 Docker Compose，然后在项目根目录执行：

```bash
docker compose up -d
```

启动完成后，打开：

```text
http://localhost:5030
```

## 主要改动

- 新增 Git 项目管理菜单，支持远程 URL、HTTP/SSH 验证、账号密码、拉取代码、切换分支和自定义拉取路径。
- 修复Crawlab分页筛选缓存。
- 新增环境依赖隔离，支持python版本和包切换。
- 爬虫创建时支持选择 Git 项目，任务启动前会先切换到该 Git 项目根目录。
- 支持自定义爬虫最大运行时间。
- 任务列表和任务详情不再显示或统计“结果数”。
- 去除了 Crawlab 框架中 Scrapy 兼容相关逻辑。
- 去除了直接将爬虫结果写入 MongoDB 的流程和逻辑。
