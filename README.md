# Crawlab-fixed

基于 Crawlab 二次修改的爬虫管理平台，修复并调整了 Git 集成、环境依赖隔离、分页筛选缓存、任务最大运行时间等功能，并去除了结果直接入库流程。

## 快速开始

请先安装 Docker 和 Docker Compose，然后在项目根目录执行：

```bash
docker compose up -d
```

启动完成后，打开：

```text
http://localhost:5030
```

## 与原版相比的主要修改

### 1. Git 项目管理

- 新增“Git项目”菜单，支持创建、编辑、拉取、删除和查看状态。
- 支持 HTTP 和 SSH 两种认证方式；HTTP 支持账号密码或 Token，SSH 支持私钥内容。
- 新建项目时，拉取路径默认生成到 `/root/{项目名称}`，也可以手动修改。
- 新建项目时不再填写或保存分支；项目创建后通过“切换分支”从远程分支列表中选择分支。
- 拉取和切换分支由后端执行 Git 命令，并保存当前分支、远程分支和操作状态。
- 爬虫可以选择 Git 项目。任务执行时会先进入所选 Git 项目的根目录，再执行爬虫命令。
- 删除 Git 项目时会同时清理对应的项目代码目录。
- 移除了原来“每个爬虫单独配置 Git 拉取代码”的旧使用方式，统一由 Git 项目菜单管理。
- 密码和私钥只写不读：接口不会返回已保存的密码，编辑项目时密码框始终为空，留空表示保持原密码；切换 HTTP / SSH 认证方式时需要重新填写。

### 2. 命令和任务执行

- 定时任务不再显示、填写或存储“命令”字段。
- 任务不再保存命令快照；每次实际执行或重试时，都会重新读取所选爬虫当前的命令。
- 修改爬虫命令后，不需要逐个同步定时任务或历史任务配置。
- 新建任务时命令由所选爬虫提供，页面不再要求用户重复输入执行命令。
- 定时任务和即时任务均支持设置“最大运行时间（秒）”。
- 任务创建时会保存本次运行的最大运行时间；任务重试时会继承原任务的最大运行时间。
- 任务开始运行后由 Runner 计时，到达限制后自动取消对应进程。
- 任务详情中增加最大运行时间显示。
- 删除任务列表和任务详情中的“结果数”显示及统计。

### 3. 定时任务和 Cron

- 定时任务命令始终来自选中的爬虫，定时任务自身不再维护命令字段。
- Cron 表达式同时兼容传统 5 位格式和带秒的 6 位格式。
- 保留时区配置，Compose 示例使用 `Asia/Shanghai`。
- 服务启动时会重新注册数据库中已启用的定时任务，避免已有任务必须等下一次刷新后才生效。

### 4. Python 环境依赖

- Python 环境按环境目录隔离，支持选择 Python 版本并单独安装包。
- 使用 `uv` 创建虚拟环境、查询包列表和安装依赖；运行任务时会自动使用所选环境的 Python。
- “环境依赖 / 包管理”支持上传 `requirements.txt`。
- 上传文件仅接受文件名为 `requirements.txt` 的文件，并限制文件大小。
- requirements 中的包会逐项安装，单个包失败时会返回明确的失败包名和错误信息。
- 若环境目录不存在，包列表、安装包和运行任务前会先创建虚拟环境。
- Docker 运行镜像内置 `uv`，避免运行时出现 `uv: executable file not found`。

### 5. 列表、筛选和导航体验

- 项目、爬虫、定时任务和任务列表的筛选条件、分页状态在进入对应菜单时统一重置。
- 支持项目筛选；定时任务和任务列表增加项目筛选项。
- 已选择筛选条件的筛选控件会显示为蓝色，表头中已使用筛选的字段也会高亮。
- 从列表进入详情再返回时，筛选控件会正确显示当前实际筛选值，不再显示“全部”但仍然保留筛选效果的不一致状态。
- 点击筛选控件的清除按钮时，会同时清除控件显示值和后端查询条件。
- 优化筛选变更和菜单切换流程，减少重复列表请求造成的页面短暂停顿。
- 移除详情页左上角的返回按钮，统一使用侧边菜单和标签页导航。
- 用户菜单固定在侧边栏底部，并且仅管理员可见；普通用户不会显示该菜单。
- Git 代码拉取和分支管理统一由“Git项目”菜单维护，爬虫创建页面不再承担单独的 Git 拉取配置。
- 定时任务列表新增“最近状态”列，位于“Cron 表达式”和“是否启用”之间，直接显示该定时任务最近一次执行的任务状态。

### 6. 凭据与敏感信息保护

- Git 项目的密码/私钥以及用户密码等凭据字段只写不读，任何接口都不会返回已保存的值。
- 导出（CSV / JSON）在写出前剔除敏感字段，避免绕过模型层直接读取数据库原始文档时把密码写进导出文件。
- 筛选选项接口拒绝敏感字段，不能通过它枚举出密码取值。

### 7. 已移除的功能和旧代码

- 删除 Scrapy 兼容相关逻辑，当前框架不再提供 Scrapy 专用兼容流程。
- 删除 Crawlab 直接把爬虫结果写入 MongoDB 的流程和相关结果入库逻辑。
- 删除旧的数据源、数据集合、结果服务和进程守护等未使用模块及其关联接口。
- 删除旧的爬虫文件控制器和未使用的在线文件操作接口；爬虫代码应通过 Git 项目目录或代码同步机制提供。
- 删除前端补丁脚本，当前修改直接落在前端源码中，不依赖构建时注入补丁。
- 删除未再调用的旧模型、接口、控制器和测试文件，减少无效代码和构建内容。
